# 모바일 청첩장

GitHub Pages에서 사용할 수 있는 모바일 청첩장 템플릿입니다.

## 파일 구성
- `index.html` : 페이지 내용
- `style.css` : 디자인
- `script.js` : 사진 클릭 확대 기능
- `images/` : 사진 폴더

## 수정할 곳
`index.html`에서 다음 내용을 원하는 정보로 변경하세요.
- 신랑/신부 이름
- 결혼 날짜와 시간
- 예식장 이름/주소
- 교통 및 주차 안내

사진은 `images` 폴더에 넣고 아래 파일명을 맞춰주세요.
- `main.jpg`
- `photo1.jpg` ~ `photo6.jpg`

## GitHub Pages
Repository를 `YOUR_ID.github.io`로 만든 뒤 파일을 업로드하고,
Settings → Pages → Deploy from a branch → `main / root`를 선택하면 됩니다.
